# Changelog

All notable changes to `ai-media-cost-guard` are documented in this file.

## [1.0.0] - 2026-11-25

### Added
- Pre-flight credit and USD cost simulator supporting per-call, per-second, and per-character pricing models.
- Budget gate enforcing maximum per-call USD limits and remaining credit balances.
- CLI (`cost-guard`) and multi-version GitHub Actions CI matrix.
